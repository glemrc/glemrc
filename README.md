# Hola, soy Glem Ramos 👋

Ingeniero de Tecnologías de Información y Sistemas (Universidad ESAN), en Lima, Perú. Trabajo con **datos de principio a fin**: bases de datos, pipelines ETL, analítica, dashboards ejecutivos y automatización con IA.

Hoy lidero la **Hoja de Ruta de IA y la gestión de datos en FUTEC**. Antes construí un sistema de optimización de dosificación para una EPS (EMAPA Huaral) con FastAPI, React y Supabase, y automaticé la recolección de datos de conferencias académicas en el Vicerrectorado de Investigación de ESAN.
